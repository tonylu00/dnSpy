# Retained field data

Non-literal Constant rows are metadata defaults, not writes to field storage.
RVA fields instead carry initial data in the PE image. A C# declaration alone
cannot preserve either form, and a missing RVA can turn a direct field read
into zero or break RuntimeHelpers.InitializeArray.

SDK export records retained field names, flags, typed constants and RVA bytes
in field attributes. The build task restores the existing definitions after
name restoration, without changing references or adding runtime assignments.
Constants use binary encodings to retain floating-point bits and raw UTF-16 code
units. CompilerControlled visibility is restored too. Runtime outputs remove
the instructions. This handles emitted fields; fields on implementation types
eliminated or regenerated by the compiler require separate reconciliation.

Run `Invoke-FieldDataRegression.ps1 -DnSpyConsole <exe> -OutputDirectory <new
folder>`. It compares exact field flags, signatures, constant types/values and
RVA bytes, then tests direct RVA reads, array initialization, zero-initialized
storage and a constructor-assigned value distinct from its metadata default.
The cases include all primitive constant kinds, negative zero, NaN payload bits,
embedded NUL/unpaired UTF-16 surrogates, nulls and CompilerControlled fields.
Rebuilt and unchanged binary clients pass; source determinism across one/four
workers, input hashes and incremental DLL/PDB hashes are checked.
