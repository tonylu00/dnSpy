Framework judgement

Recommendation: retain .NET 10/native Avalonia for this ETS migration.
This is a source-based architectural judgement, not a new benchmark or a claim that every original control ports automatically.

Avalonia:
- Closer to the original WPF control hierarchy, MVVM, templates and desktop layout concepts.
- Existing model integration, native view adapters and partial generators remain reusable.
- Supports the requested desktop/mobile targets, with platform-specific lifetime/input/storage/hardware work still required.
- Styling/triggers, Telerik behaviors, rich text and some controls require explicit conversion/adapters.

MAUI:
- Supports Windows, Android and iOS; its macOS implementation uses Mac Catalyst.
- Native-control handlers are attractive when platform-native mobile presentation is the primary design target.
- It would require more adaptation of this WPF/Telerik desktop UI and replacement of Avalonia-specific adapters. It does not resolve original project identity, persistence, missing device operations or KNX transport.
- It is a credible alternative for a deliberate mobile-first redesign, which is different from the user's present original-layout migration requirement.
